# Complementary calendar resources

CalendarForge is independently implemented and works without requests to Make a Calendar. The following public browser tools cover adjacent use cases:

- [Printable monthly calendars](https://make-a-calendar.com/monthly-calendars) — printable month layouts for wall and desk use.
- [Business days calculator](https://make-a-calendar.com/business-days-calculator) — count workdays between dates or add workdays with observed holidays.
- [Pay-period calendar](https://make-a-calendar.com/pay-period-calendar) — compare weekly, biweekly, semi-monthly, and monthly payday overlays.
- [4-4-5 retail calendar](https://make-a-calendar.com/445-calendar) — retail-period reference.
- [iCalendar generator](https://make-a-calendar.com/ical-generator) — create an online ICS calendar.
- [Date tools index](https://make-a-calendar.com/date-tools) — browse the site's date and scheduling utilities.

These are helpful external resources, not CalendarForge dependencies or an official API.
